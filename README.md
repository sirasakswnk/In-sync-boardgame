# IN SYNC

เว็บเกมจัดอันดับสำหรับสองคน — เรียงของที่ชอบ ทายใจอีกคน แล้วเปิดเฉลยพร้อมกัน

**เล่นได้ที่ <https://heartsyncboardgamebymingmx.vercel.app>**

---

## เกมนี้เล่นยังไง

หนึ่งเกมมี 6 รอบ แต่ละรอบสลับบทบาทกัน

1. **คนวาง** เรียงไพ่ 5 ใบตามใจตัวเองลงแท่นอันดับ
2. **คนทาย** เรียงตามที่คิดว่าอีกฝ่ายเรียงไว้ ระหว่างนั้นคนวางเห็นไพ่ขยับแบบสด ๆ แต่ยังไม่เห็นคะแนน
3. เปิดเฉลยทีละใบ คะแนนเข้าคนทาย ตรงเป๊ะได้ 2 ห่างหนึ่งอันดับได้ 1

จบ 6 รอบ แต่ละคนได้ทาย 3 รอบ เต็มคนละ 30 คะแนน แล้วดูว่าใครรู้ใจอีกฝ่ายมากกว่ากัน

## จุดเด่น

- **เล่นสองคนจริง ๆ** คนละเครื่องหรือคนละเบราว์เซอร์ ผ่านห้องที่มีรหัส 6 ตัว ไม่ต้องสมัครสมาชิก
- **คำตอบเป็นความลับจนถึงเวลาเฉลย** บังคับที่ชั้นฐานข้อมูล ไม่ใช่แค่ซ่อนใน UI
- **กลับเข้าเกมเดิมได้** รีเฟรช ปิดแท็บ หรือเน็ตหลุดแล้วกลับมานั่งที่เดิม และหนึ่งคนอยู่ได้ครั้งละห้องเดียวแม้กดจากหลายแท็บพร้อมกัน
- **ธีมโต๊ะบอร์ดเกม** ไพ่ แท่นอันดับ ถาดไม้ และใบโน้ตกระดาษ ออกแบบมาเพื่อจอมือถือก่อน และจัดเป็นสองคอลัมน์บนจอคอมพิวเตอร์
- **UI ภาษาไทยทั้งหมด** วางไพ่ด้วยการลากหรือแตะไพ่แล้วแตะช่อง

## เทคโนโลยี

Next.js 16 (App Router) · React 19 · TypeScript · Firebase Realtime Database + Anonymous Auth · CSS Modules · Vitest · deploy บน Vercel

กติกาทั้งหมดเป็น pure function ที่ทำงานใน transaction เดียวของฐานข้อมูล ส่วนผู้เล่นแต่ละคนอ่านได้เฉพาะมุมมองของตัวเองที่ server สร้างให้

## รันในเครื่อง

```powershell
npm ci

# หน้าต่างที่ 1 — Firebase emulator (ไม่ต้องมีบัญชี Firebase)
npm run emulators

# หน้าต่างที่ 2 — เว็บ
npm run dev:emulator
```

เปิด <http://localhost:3000> แล้วเปิดอีกหน้าต่างแบบ incognito เพื่อเล่นเป็นผู้เล่นคนที่สอง

วิธีต่อ Firebase project จริง การทดสอบ การ deploy และรายละเอียดอื่น ๆ อยู่ใน [คู่มือนักพัฒนา](docs/DEVELOPMENT.md)

## โครงสร้างโดยย่อ

```text
src/app/          หน้าเว็บและ API routes
src/features/     หน้าแรก และหน้าต่าง ๆ ในห้องเกม
src/components/   การ์ด อวาตาร์ ปุ่ม และฟอร์มที่ใช้ร่วมกัน
src/lib/game/     กติกาและคะแนน (ไม่ผูกกับ Firebase)
src/lib/server/   ฝั่ง server: auth, transaction ของห้อง
src/lib/client/   ฝั่ง client: realtime, ร่างที่บันทึกไว้
tests/            unit tests และ integration tests
```
